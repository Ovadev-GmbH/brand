# @ovadev-gmbh/ui-internal

Ovadev's design system in light mode, for the internal tools. Since 1.0.0
this package re-exports `@ovadev-gmbh/ui-ovadev` and adds one stylesheet,
`src/internal.css` (generated by `scripts/gen-internal.ts`): light as the
default, and the `--int-*` custom properties as aliases of `--ova-*`.

`data-theme="dark"` on `<html>` gives a tool Ovadev's dark mode;
`data-theme="system"` follows the OS. New code imports from
`@ovadev-gmbh/ui-ovadev` directly.
