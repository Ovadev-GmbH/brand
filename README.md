# Ovadev Brand

Shared brand packages live in `packages/`; the catalog in `site/` is served at `intern.ova.dev/brand`. Build and typecheck with the root Bun scripts.

Auth uses one Ovadev design, with service-specific identity assets. Its components belong to [SrvFrontAuth](https://github.com/Ovadev-GmbH/SrvFrontAuth/tree/staging/src/design-system). [Ops → Frontends → Branding](https://ops.backend.ovadev.dev/frontends?view=branding) renders those components from the deployed Auth release; this repository links to that catalog instead of duplicating it. Private Ops access is required.
